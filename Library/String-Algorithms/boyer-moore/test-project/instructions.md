# How to run the test project

This is a simple interactive CLI application to demonstrate the Boyer-Moore string search algorithm.

## Prerequisites
- Python 3.x installed on your system.

## Running the Application
1. Open a terminal or command prompt.
2. Navigate to the `test-project` directory:
   ```bash
   cd Library/String-Algorithms/boyer-moore/test-project
   ```
3. Run the application:
   ```bash
   python app.py
   ```
4. Follow the on-screen prompts to input a text and a pattern to search for. The application will output the starting indices of all occurrences and visualize the first occurrence.
